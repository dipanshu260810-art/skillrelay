# SkillRelay

Convert skill ZIPs and `SKILL.md` files for Claude and ChatGPT. SkillRelay runs in your browser and keeps the files on your device during conversion.

## Use the converter

1. Open [SkillRelay.html](./SkillRelay.html) and select **Download raw file** in GitHub.
2. Open the downloaded file in your browser. Select **Try sample** for a demo, or choose a direction and add your own skill.
3. Select **Convert**, review the compatibility report, and download the new ZIP. If you use a regular chat, you can copy the converted instructions from the result.

The **Chat handoff** tab turns a selected draft and request into text you can review and copy into another chat. It also exports a JSON file you can reopen later.

## Source and local MCP

Download and extract [SkillRelay-source.zip](./SkillRelay-source.zip) for the editable project, command-line converter, tests, and documentation for connecting two compatible local MCP clients. Start with the README inside the archive. The project is available under the [MIT license](./LICENSE).
